# Code Katas Workshop

## Learning objectives

By the end of this workshop you can take a small problem and get from a blank file to working code, one step at a time.

1. **Break down problems** – split a problem into small, manageable pieces you can tackle one at a time.
2. **Describe steps in plain English** – write out what each piece needs to do in everyday words, before writing any code.
3. **Sort steps by order of implementation** – decide which step comes first, so each one builds on the one before.
4. **Implement them** – turn each plain-English step into code, checking it works before moving on.

## Exercises

### In the workshop

- `exercise_1_easy.py`
- `exercise_2_medium.py`
- `exercise_3_hard.py`

### After the workshop

1. Clone this repository (or download it) to your machine.
2. Work through the post-workshop exercises in order:
   - `post_workshop_exercise_1_easy.py`
   - `post_workshop_exercise_2_medium.py`
   - `post_workshop_exercise_3_hard.py`
3. For each one, use the same four steps: break it down, describe it in plain English, sort the steps, then implement.

> **Finding it hard?** That's fine. Start by solving the three workshop exercises (`exercise_1_easy.py`, `exercise_2_medium.py`, `exercise_3_hard.py`) again from scratch, without looking at the workshop solutions. Then move on to the post-workshop ones.
